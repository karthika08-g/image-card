# React Image Gallery

## Project Description
The React Image Gallery is a responsive web application developed using React.js and Tailwind CSS. It displays a collection of beautiful images in an attractive card-based grid layout.

The project uses reusable components, React props, and the JavaScript map() method to dynamically display multiple images.

## Features
- Responsive image gallery layout
- Reusable ImageCard component
- Dynamic image rendering using map()
- Data passing using React props
- Beautiful card design with hover effects
- Tailwind CSS styling
- Mobile-friendly design

## Technologies Used
- React.js
- JavaScript
- Tailwind CSS
- HTML
- Vite

## Project Structure
- App.jsx – Main application component
- ImageCard.jsx – Reusable image card component
- main.jsx – Application entry point

## How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL in your browser.
